# TEST REPORT — BOTVEX Order Bot v4

## Выполнено в доступной сборочной среде

- `python -m compileall -q bot.py app tests` — PASS.
- `python -m unittest discover -s tests -v` — **46 тестов пройдены**.
- Проверена работа SQLite unit-тестов на временных базах: создание заявки, история событий, переходы статусов, назначение цены, уведомления, уточнения, права владельца, миграции и ссылки панелей.
- Проверены статические контракты обработчиков: молчаливый неавторизованный `/admin`, отсутствие кнопки клиентской истории, управление панелями администратора и клиентскими уведомлениями.
- ZIP прошёл проверку целостности, распакован в чистую директорию; `python -m compileall -q bot.py app tests` и `python -m unittest discover -s tests -v` после распаковки — PASS, **46 тестов пройдены повторно**.

## Не проверено в этой среде

- Импорт и запуск приложения с настоящей `aiogram`: пакет в среде сборки отсутствует, а сетевой доступ для установки недоступен.
- Реальные отправка, редактирование и удаление сообщений через Telegram Bot API.
- Выполнение `update_botvex.ps1` в Windows PowerShell 5.1.
- Визуальное отображение на реальных клиентах Telegram Android, iOS, Desktop и Web.
- Реальная миграция пользовательской production-базы. Перед обновлением скрипт делает резервную копию и выполняет идемпотентную инициализацию.

## Ручная приёмка на целевом ПК

После обновления выполни команды из README и проверь `/start`, `/admin` с обычного и администраторского аккаунта, создание заявки, изменение статуса, уведомление и переход в карточку, запрос уточнения/ответ, назначение цены, удаление входящих сообщений и восстановление черновика после перезапуска.

Этот отчёт не заявляет о production-ready состоянии до проверки настоящего Telegram API и Windows.
